# 程序代码相似度检测系统

## 项目简介

这是一个基于余弦相似度算法的C语言代码相似度检测系统，用于识别和比较源代码文件之间的相似程度。该系统广泛应用于学术诚信、软件开发质量控制、版权保护及安全审计等多个领域。

## 功能特性

1. **代码预处理**：自动过滤注释、头文件、字符串字面量、空格和空行等无关信息
2. **代码转换**：将预处理后的代码转换为标记序列（Token序列）
3. **相似度计算**：使用余弦相似度算法计算两个代码文件的相似度
4. **抄袭评估**：根据多个阈值标准判断代码是否涉嫌抄袭

## 系统架构

### 模块划分

- **utils.c/h**：工具函数模块（文件读写、动态字符串、字符串数组）
- **preprocess.c/h**：代码预处理模块（去除注释、头文件等）
- **tokenize.c/h**：代码标记化模块（将代码转换为标记序列）
- **similarity.c/h**：相似度计算模块（余弦相似度算法）
- **evaluate.c/h**：抄袭评估模块（阈值判断）
- **main.c**：主程序（整合所有模块）

## 测试数据

测试数据位于 `test_data/` 目录下：

- `code1.c` 和 `code2.c`：相似的斐波那契数列程序（预期高相似度）
- `code1.c` 和 `code4.c`：相似但变量名不同的程序（预期高相似度）
- `code1.c` 和 `code3.c`：完全不同的程序（预期低相似度）

## 阈值标准

系统提供三个阈值标准来判断代码相似度：

- **严格标准**：相似度 >= 0.8（高度相似）
- **中等标准**：相似度 >= 0.6（中度相似）
- **宽松标准**：相似度 >= 0.4（低度相似）
- **不相似**：相似度 < 0.4

## 算法说明

### 余弦相似度算法

余弦相似度通过计算两个向量之间的夹角余弦值来衡量相似程度。在本系统中：

1. 将代码转换为标记序列
2. 统计每个标记的词频，构建词频向量
3. 计算两个词频向量的点积和模长
4. 相似度 = 点积 / (向量1模长 × 向量2模长)

### 代码预处理

- 去除单行注释（`//`）
- 去除多行注释（`/* */`）
- 去除头文件包含（`#include`）
- 去除字符串字面量（`"..."` 和 `'...'`）
- 去除多余的空格和空行

### 代码标记化

- 识别C语言关键字（如 `if`, `for`, `return` 等）
- 识别运算符和分隔符（如 `+`, `-`, `==`, `(` 等）
- 将标识符统一替换为 `IDENTIFIER`
- 将数字统一替换为 `NUMBER`

## 技术特点

- 使用C语言实现，充分利用C语言在数据处理和算法实现方面的优势
- 模块化设计，各功能模块独立，便于维护和扩展
- 支持动态内存管理，适应不同大小的代码文件
- 提供详细的运行日志，方便调试和分析

## 注意事项

1. 系统主要针对C语言代码设计，对其他语言的检测效果可能有限
2. 相似度值仅供参考，最终判断需要结合具体场景和人工审核
3. 系统对代码格式变化、变量名替换等有一定的鲁棒性
