### 📝 技术特点

1. **模块化设计**：各功能模块独立，便于维护和扩展
2. **动态内存管理**：使用动态内存分配，适应不同大小的代码文件
3. **鲁棒性**：对代码格式变化、变量名替换等有一定的鲁棒性
4. **详细日志**：提供详细的处理过程输出，方便调试和分析

### 🎯 算法说明

**余弦相似度算法流程：**

1. 代码预处理 → 去除无关信息
2. 代码标记化 → 转换为标记序列
3. 构建词频向量 → 统计每个标记的出现频率
4. 计算余弦相似度 → `相似度 = 点积 / (向量1模长 × 向量2模长)`
5. 评估结果 → 根据阈值判断是否抄袭

### ⚠️ 注意事项

1. 系统主要针对C语言代码设计
2. 相似度值反映的是代码结构相似性，而非功能相似性
3. 最终判断需要结合具体场景和人工审核
4. 系统对代码格式变化、变量名替换等有一定的鲁棒性
